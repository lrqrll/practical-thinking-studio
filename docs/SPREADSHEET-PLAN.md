## M1 實際證據與限制

- `npm run test:unit`：31/31通過（既有6＋新核心25），0失敗／跳過；父代理檢查實際差異後執行。新核心未載入index、未接觸IndexedDB、未註冊新工具。
- 支援不可變更的多表／儲存格編輯、格式欄位、快照計算、相依重算、循環／錯誤隔離、中文及引號跨表、範圍、SUM/AVERAGE/MIN/MAX/COUNT及懶惰IF。CSP禁止動態程式生成時仍可計算，惡意公式不執行程式。
- 父代理將已支援算術的負號／連續次方改為Excel順序：`=-2^2`為4，`=2^3^2`為64；修正前新增預期失敗、修正後通過。不宣稱其餘公式全部相容。

- 真正網格、列欄／複製貼上、排序篩選、CSV/XLSX、自動保存與歷史整合仍待完成，不能稱為已可操作的Excel。
