# 智慧工作台 M2 資料契約（實作前規格）

正式基線：3.3.0，main ff3f8a16cb343b93973bd191003c30ca9c13b996，發布與獨立QA已結案。M2只授權分支、測試、PR與隔離預覽，不合併／部署；不恢復獨立Excel。

## 欄位與缺值

- M1工作台schemaVersion=1不自動改寫。首次新增欄位／從範本建立才使用schemaVersion=2、fieldStructureVersion=1、fields及values。
- fields為有序陣列，id永久穩定；label最長100字。型別text／number／date／select，另有money沿用TWD整數分規格。型別與單選選項建立後固定；變更需求以新增欄位處理，避免默默轉換舊值。
- 文字最多20,000字，保存原字串；數字以字串儲存，最多30數字、12小數位、可正負，不做浮點運算或四捨五入，不接受科學記號。日期為0001–9999年有效YYYY-MM-DD，不受時區影響。單選以穩定option ID儲存（最多30項，每項100字）。金額使用既有NexusMoney，非負、精確至分與相同上限，不截短舊值。
- null／空字串是未填，數字0是明確值；文字空白判為未填但raw保留。無效raw仍可保存，顯示錯誤，不能建立成果。不可用NaN／Infinity或日期自動進位來代替驗證。
- 最多40使用中欄位、100欄位含移除項。移除為deletedAt軟刪除，保留定義、ID及值；含任何原值時需確認。可原ID恢復，沒有自動清除或永久刪欄位。
- 改名／排序只改定義，值由ID關聯。未知屬性／未知值鍵保留於保存及完整備份；未知型別只讀，阻擋新成果或範本套用，不能默默清空。遇schema1既有不明fields/values擴充時拒絕覆寫，不猜測遷移。

## 範本與複製隔離

meta的workbench-template:記錄schemaVersion=1、rev、name、fields、defaults、deletedAt。最多100份含垃圾桶，支援CAS修改、移除／恢復。

從工作台存範本只複製使用中欄位的已知結構（名稱、型別、選項）；defaults初始為空，預設值必須在範本編輯器明確輸入並驗證。欄位名稱及選項也是結構，儲存前可檢查。完全不讀取／複製來源文件內容、工作台值、成果、歷史、附件或來源ID。

由範本建立新工作台時給予新工作台／欄位／選項ID並映射明確預設值，modules為空，不共用來源。範本後續修改／刪除不影響已建工作台。移除含預設值的範本欄位亦確認及可恢復。

## 固定成果與輸出

純M1工作台沿用schema1成果與原CSV／JSON格式；M2工作台新成果schemaVersion=2、fieldStructureVersion=1，凍結使用中欄位定義、raw、型別化值與順序。金額為minor/currency/scale，數字為精確十進位字串，未填為null。舊schema1／schema2成果不因現行欄位或範本變動而改寫。

新CSV以固定快照為唯一來源，欄名帶欄位ID避免同名錯置；JSON成果交換version=2。文字／單選／欄名維持CSV注入防護，負數純數字依驗證後的數值輸出。成果原有1,000,000 JSON字元上限保持，超限拒絕，不刪或截短。

## 備份、還原與保存

無M2資料時仍匯出v1／v2；有M2工作台／成果／範本才用完整備份v3。v1／v2仍可使用，所有來源、文件、歷史、封存、偏好保持。v3加入workbenchTemplates；完整分包與SHA-256傳輸規格不變（100MB單檔門檻，超過自動16MB分包）。不以選取檔案匯出冒充完整恢復。

先驗證整份圖譜，再同一IndexedDB交易建立副本，重映射工作台／欄位／選項／模組／來源／成果／範本ID；保留raw、歷史、版本與未知屬性，不覆寫原資料。配額／驗證／CAS失敗回滾且可重試。不升IndexedDB版本、不全面重寫資料層。

欄位值與範本採明確保存，離開未保存編輯須確認；保留分頁隔離的恢復草稿，失敗不清除草稿。完整備份只含已保存內容，頁面須明示。

## 拆分與驗收

1. 欄位／範本純模型、此契約及單元（不加入產品入口）。
2. 基於1的保存、快照、備份v3與原子還原（API瀏覽器驗證）。
3. 基於2的完整介面、手機／鍵盤／明暗／axe與獨立M2預覽。

保留3.3.0容量、八工具與文件選取回歸。新測試包括ID穩定、缺值／錯誤raw、刪除恢復、範本隱私及獨立性、舊資料不改寫、固定快照、CSV／JSON、v1/v2/v3與超100MB還原、配額回滾／衝突。開發者綠燈不等於獨立QA通過。實機跨瀏覽器／OS／Office與配額／記憶體限制如實保留。


## 介面與候選整合細節

- 明確儲存不在每次打字重繪畫面；保存／CAS失敗保留輸入、可重試，不阻擋後續保存。未保存離開需確認，頁面關閉有提醒；分頁隔離localStorage草稿可在重開時復原成新副本，原資料不覆寫，工作台草稿副本不連結來源。範本草稿可修正錯誤後另存新範本。草稿備援配額失敗會提示；下載草稿JSON僅作留存，不冒充完整備份。
- 不理解的值鍵不重命名；副本保留原鍵與opaque關聯。已知欄位／選項才重映射ID。金額型別化值驗證不依賴JSON屬性順序；無效或未知raw不默改。
- 保持M1的報價＋備忘來源完整性要求，範本新工作台需另行建立／連結來源才能建立完整成果。沒有新增通用模組或其他大型工具。
- 型別與選項固定；範本移除項的raw預設值保留，但不套用到新工作台。新成果依舊最多100萬JSON字元，超限明確拒絕、不截短；工作資料仍可完整備份。
- 候選3.4.0-rc.1；M2預覽位於既有預覽庫的m2/，使用nexus-preview-workbench-m2-workspace及nexus-preview-workbench-m2-recovery:。既有M1根預覽、斜體預覽與正式站的命名空間不變，不自動移入資料。路徑共用origin，只是應用資料命名空間隔離。
