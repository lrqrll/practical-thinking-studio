## 目前發布狀態與限制

正式仍為main a0edd157ef1a01572e296db01c23f9a8b9651a76／3.2.1。本分支準備3.2.2，尚未合併／部署。

- **DOC-SELECT-02（P1已解除，保留歷史）**：先前PR #5已獲批准並部署到main a0edd157ef1a01572e296db01c23f9a8b9651a76。正式驗收[39985267265](https://github.com/lrqrll/practical-thinking-studio/actions/runs/39985267265)核對26個公開資產與15次文件專項；使用者核對原始證據後確認解除。不可沿用舊「待批准PR #5」描述為現況。
- **RELEASE-01**：3.2.1既有驗收完成；新的3.2.2／3.3.0發布準備不等於已部署，仍待具體PR／SHA批准。
- **COMPAT-01（P2）**：File System Access 的實機選擇器、OS 權限拒絕、Firefox／Safari 下載匯入替代路徑尚未完成實機驗收。自動測試驗證 Chromium UI 和 API 替身協定，不冒稱已測 OS 對話框。
- **PRINT-01（P2）**：已驗證列印 frame 與由同內容產生的 PDF 結構；實際列印視窗、實體印表機、Word／LibreOffice 排版精確度仍需發布前檢視，不能保證完全還原 DOCX 版型。
- **VENDOR-01（P2）**：vendor bundle 缺少可重建的原始 lockfile／build 腳本；授權清單含多個版本，不能據此推定實際 bundle 精確版本。npm audit 僅涵蓋新加入的 QA 依賴，不能代表所有嵌入式依賴已稽核。
- **CAPACITY-01（P2）**：最近十次歷史含完整內容和圖片，也占用瀏覽器配額；兩層儲存都可能失敗。錯誤時可重試、下載最新草稿或直接另存工作檔，沒有無限容量／強制結束零資料損失保證。
- **QA-01（P2）**：目前只在 Linux Chromium 執行；無真實手機觸控／螢幕閱讀器／跨瀏覽器長時間壓力測試。axe 零違規僅代表已測規則與頁面狀態，不代表完整無障礙認證。
