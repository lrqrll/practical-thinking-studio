# 模型與執行策略

此為 NEXUS 持續準則；不擴大合併、部署、資料刪除或付費資源的授權。一般工作由主代理處理，不為每個小修改另啟動審查。

## 能力與誠實回報

- 每個新環境先確認：主代理模型／推理是否可查，是否有實際切換工具，子代理能否指定模型與推理。不可用風格、速度或猜測辨識模型。
- 分開描述「主代理切換」「主代理未切換、委派其他模型」「只調整推理」與「需使用者手動設定」。無法確認就標示「環境未提供可確認資訊」，繼續不受影響的工作。
- 2026-10-24 本環境：無主代理模型／推理查詢或切換工具；子代理介面提供 gpt-6.1-sol、gpt-6-astra、gpt-6-sol、gpt-6-luna、gpt-5.6-sol，可指定 reasoning_effort。這是介面可選清單，不代表已呼叫成功、已切換主代理或已知帳號用量。
- 不另購方案、不用付費 API 或新 API key；不能用 token 標價推算 Work／Codex 帳號扣用量，用量未知就標示未知。

## 預設與升級

- 可設定時預設 GPT-6.1 Sol High；文件、文字及單純低風險 UI 可用 Medium。保存、遷移與發布判斷不為省用量降低必要深度。
- 保存競態、多分頁、遷移／恢復、公式相依／循環、大量共享狀態與相互矛盾的 CI／瀏覽器證據，先評估 Sol Extra high；有具體難題才考慮 Astra。無法切主代理時可委派，必須如實說明。
- 同一 P0/P1 經兩輪有假設、有修正、有針對性驗證仍失敗，或證據不足以解釋偶發問題、多個競爭假設、可能不可逆資料遺失、核心模型／公式／儲存的廣泛變更，須評估升級。高風險可直接升級；盲重跑不算修正一輪。
- 先排除 401/403、套件與瀏覽器下載、Pages 尚未完成、舊快取／錯誤站點／SHA、未啟動服務與埠衝突。模型切換不能修復權限；等待 CI 或下載不額外啟動高推理分析。

## 子代理與停止條件

- 使用者已授權必要時委派。通常先一個分析型唯讀代理，提供 SHA、檔案、日誌、重現、限制與預期輸出；真正獨立的問題才增加代理。修改時明確分配檔案責任。
- 升級前簡記：卡點、現有證據、已排除假設、具體問題、成功判準與停止條件。不要用「全面檢查」作為無邊界任務。
- 主代理須驗證代理推論、diff 與測試；不讓多代理各自重跑整套測試或重複分析同一問題。委派不授權聊天、GitHub 評論、郵件或外部訊息。
- 根因有證據、範圍清楚、針對性回歸通過後結束高成本代理；可設定時回 Sol High。無切換工具不可聲稱已降回。

## 測試與紀錄

- 確定性工作交給程式與 Actions。先針對性驗證，再做適當完整回歸；沒有新變更、失敗或疑慮不重複整套。
- 偶發問題可有限重複，明列通過、失敗、跳過、重試及次數；重複不能取代根因。保留失敗，不忽略例外或降低斷言換綠燈。
- 保留簡潔證據與接續文件，不重讀／重建整站。只在模型策略實質改變時回報實際可確認設定、代理模型、原因、結果及風險；一般進度聚焦產品與阻擋。
- 授權、資料安全、正式 HTTPS 驗收門檻及產品規則依 AGENTS；禁止降低 TLS 或持久加入代理 CA。所有正式阻擋解除後才恢復 Excel，不能用預算試算或簡報大綱冒充完整編輯器。
